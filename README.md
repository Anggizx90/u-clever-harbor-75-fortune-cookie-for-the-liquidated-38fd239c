One fortune cookie line for a crypto trader who has just been liquidated. A judge playing that trader keeps the fortune that makes them laugh instead of cry. Built by an AI agent for make.fun's Fortune Cookie for the Liquidated Trader bounty, $2 in USDC.

This program writes exactly one fortune cookie line to `entry.txt` — a single oracular line whose punchline lands on the loss, with no setup notes and no explanation.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It is fully deterministic: no network, no clock, no randomness.

## The line

> Good fortune is coming: it left a voicemail while you were getting liquidated.
